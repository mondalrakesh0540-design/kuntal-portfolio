## 🛠️ Step-by-Step GitHub Upload & Deployment Guide

### Option 1: Using GitHub Web Interface (Easiest - 1 Minute)
1. Go to [GitHub.com](https://github.com/) and create a new public repository named `kuntal-portfolio` (or `kuntalghosh.github.io`).
2. Click **"uploading an existing file"**.
3. Drag and drop all files and folders from this project (`index.html`, `css/`, `js/`, `README.md`).
4. Click **"Commit changes"**.
5. In your GitHub repository, navigate to **Settings** > **Pages** (left sidebar).
6. Under **Branch**, select `main` and `/ (root)` folder, then click **Save**.
7. Your portfolio will be live at:
   ```
   https://<your-github-username>.github.io/kuntal-portfolio/
   ```

---

### Option 2: Using Git Terminal / Command Line
```bash
# 1. Initialize git repository
git init

# 2. Add all project files
git add .

# 3. Commit changes
git commit -m "feat: initial mechanical engineering portfolio release"

# 4. Set main branch and connect remote repository
git branch -M main
git remote add origin https://github.com/<your-username>/kuntal-portfolio.git

# 5. Push code to GitHub
git push -u origin main
```

Then enable GitHub Pages under **Repository Settings > Pages > Source: Deploy from a branch (main / root)**.

## ⚙️ Interactive Mechanical Simulation Suite

| Simulator | Technologies | Highlights |
| :--- | :--- | :--- |
| **3D CAD Component Explorer** | Three.js, WebGL, OrbitControls | Exploded assembly view, PBR metallic materials (Tool Steel, Titanium, Brass, Cyan Blueprint), Wireframe toggle. |
| **Precision Gear Transmission** | HTML5 Canvas 2D, Involute Physics | Real-time gear train teeth meshing, RPM controls, pitch circles, and speed ratio readouts ($N_1/N_2$). |
| **4-Stroke Reciprocating Engine** | Canvas 2D, Kinematic Equations | Dynamic cylinder bore, piston stroke, wrist pin, connecting rod, spark combustion flash, and intake/exhaust valves. |
| **CNC G-Code Visualizer** | Canvas 2D, Digital Readout (DRO) | Line-by-line G-Code interpreter, contour cutting, cutting sparks, and coordinate tracking ($X, Y, Z, F$). |
| **VCR Thermodynamic Cycle** | Canvas 2D Vector Schematic | Industrial Refrigeration & Air Conditioning (RAC) flow loop with state point temperature gradients. |
